# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

## In short

- Be respectful. Disagree with ideas, not people.
- Assume good faith.
- No harassment, no doxxing, no slurs.
- Keep technical discussions technical.

## Enforcement

Report violations to security@metatech.id. Maintainers investigate
and act — warnings, temporary bans, or permanent removal. Reporters'
identities stay confidential.

Full text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
